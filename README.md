# Лабораторная 5: Разработка базового SPA на React

**Цель работы:** Разработка клиентской части приложения (Single Page Application) на React с использованием TypeScript, реализация навигации, фильтрации данных на стороне бэкенда и работа с внешними API.

**Задание:**
1.  **Интерфейс**: Создать 3 страницы (Главная со статикой, Список услуг, Страница услуги) на React-Bootstrap.
2.  **Компоненты**: Реализовать Navbar и самописные Breadcrumbs (цепочка навигации).
3.  **Фильтрация**: На странице списка реализовать фильтры (поиск по названию, цене, датам), отправляющие запросы на бэкенд (Go).
4.  **Данные и изображения**: 
    *   Использовать `fetch` для запросов.
    *   Реализовать "Mock-режим": если бэкенд недоступен, данные берутся из локальных объектов.
    *   Загрузка фото из **Minio** с обработкой пустых значений (заглушка default image).
5.  **CORS**: Решить проблему кросс-доменных запросов через проксирование в Vite.
6.  **Ограничения**: Запрещено использование Redux и Context API.

**Порядок показа:**
1.  **Mock-режим**: Демонстрация работы фронтенда без запущенного Go-сервиса (на моках).
2.  **Интеграция**: Запуск бэкенда, демонстрация реальных данных. Проверка вкладки *Network* (адреса fetch через `/api` proxy, ссылки на Minio).
3.  **Динамика**: Изменение записи в БД и мгновенное отображение изменений на странице после обновления.
4.  **Разбор кода**: Объяснение логики компонентов, использования хуков `useState` и `useEffect`, передачи `props` и работы фильтров.

**Диаграммы:**
*   **Диаграмма классов**: Детализация бэкенд-доменов (методы) и фронтенд-страниц. Указание зависимостей страниц от API-методов.

**Контрольные вопросы:**
*   React: компоненты vs элементы, Virtual DOM.
*   Состояние (`state`) и свойства (`props`).
*   Хуки `useState` и `useEffect`: жизненный цикл компонента.
*   CORS и механизм обратного прокси (Reverse Proxy).
*   Vite и Babel. Архитектура FSD. BFF и GraphQL.
