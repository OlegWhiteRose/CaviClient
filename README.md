# Лабораторная 6: Внедрение адаптивности и развертывание приложения

**Цель работы:** Управление состоянием приложения с помощью Redux Toolkit, обеспечение адаптивности интерфейса, развертывание в GitHub Pages и создание нативного приложения через Tauri.

**Задание:**
1.  **State Management**: Внедрение **Redux Toolkit** исключительно для хранения состояния фильтров (чтобы они сохранялись при переходах между страницами).
2.  **Адаптивность**: Настройка сетки (Grid) и колонок для корректного отображения на мобильных устройствах.
3.  **Deployment**: Развертывание фронтенда на **GitHub Pages**.
4.  **PWA**: Добавление манифеста и Service Worker для работы приложения как Progressive Web App.
5.  **Tauri**: Сборка нативного десктопного приложения, подключающегося к Go-бэкенду по IP в локальной сети.

**Порядок показа:**
1.  **Мобильный UI и PWA**: Показ GitHub Pages на телефоне, сохранение PWA-ярлыка. Демонстрация работы фильтров.
2.  **Сохранение состояния**: Изменение фильтра -> Переход на главную -> Возврат к списку (показ, что Redux сохранил значения).
3.  **Адаптив в браузере**: Демонстрация изменения количества колонок при смене ширины окна.
4.  **Tauri App**: Запуск собранного `.exe`/`.app` файла. Соединение с бэкендом не по `localhost`, а по локальному IP (например, `192.168.x.x`).
5.  **Сетевой анализ**: Определение порта Tauri через `wireshark` или `tcpdump`.
6.  **Безопасность**: Демонстрация работы по HTTPS в локальной среде.

**Диаграммы:**
*   **Deployment Diagram**: Узлы системы (Frontend, Web-server, Go-service, PostgreSQL, Minio, Redis). Указание протоколов взаимодействия (HTTP/HTTPS, TCP) и API-интерфейсов.

**Контрольные вопросы:**
*   Архитектура Flux и реализация Redux (Store, Reducer, Dispatch, Action).
*   Redux Toolkit (slice, configureStore).
*   Типы нативных приложений: PWA vs Tauri vs Electron.
*   Механизмы развертывания в GitHub Pages.
